## IEEE-style Citation

"Supplied project history and recovery notes: LoRa + LTE Hiking SOS Tracker," project prompt supplied 19 November 2026.

## Summary

A supplied recovery record identifies the intended device as a portable hiking SOS tracker for remote areas of Ireland, with LoRa off-grid communication, possible Meshtastic integration, LTE SMS, GNSS position, battery power and potential solar charging.

## What This Source Establishes

- Current LoRa working direction: Waveshare Core1262-868M.
- Current cellular/controller working direction: Waveshare ESP32-S3-A7670E-4G.
- Ebyte E220-900M22S is historical rather than current.
- A7670E Irish-network SMS operation remains unverified.
- Communication priority remains unresolved.
- No physical hardware tests have been completed according to the supplied history.
- A detailed historical component list is provided, but exact rejection reasons and specifications are not all retained.
